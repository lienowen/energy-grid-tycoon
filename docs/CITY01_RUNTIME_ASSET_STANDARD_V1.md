# City-01 运行素材统一标准 V1

## 1. 目标

City-01 不再通过错名产品图、整张精灵图、带文字碎片或临时运行时缩放拼出设施。所有可见设施必须先进入统一运行素材体系，再允许注册到全局 Asset Catalog。

本标准对应《Energy Grid Tycoon 游戏开发文档 V1.1》的地图分层与 P0 素材要求。

## 2. 目录职责

| 目录 | 职责 | 是否允许运行时直接引用 |
|---|---|---:|
| `public/assets/single/v1` | 已从源精灵表切出的透明单图 | 仅通过统一目录映射后允许 |
| `public/assets/city01/product/facilities` | 历史产品图，文件名与真实语义错位 | 否 |
| 源精灵整图 | 切图与追溯 | 否 |
| `City01UnifiedFacilityCatalog.ts` | City-01 设施运行入口 | 是 |

## 3. 设施运行规格

每个设施家族必须满足：

- 输出画布：`512 × 512`，RGBA。
- 统一锚点：`x=0.5`、`y=0.9115`。
- 统一地线：`467 px`。
- 必备状态：`active`、`construction`、`offline`、`fault`。
- 同一设施不同状态必须保持相同视觉尺度和落地点。
- 不允许烘焙名称、按钮文字、错误提示或状态说明文字。
- 不允许直接加载整张精灵表。
- 不允许透明边外残留箭头、文字碎片或其他设施残片。

运行时首次加载单图时执行：

1. 读取 Alpha 主体边界；
2. 去除极小边缘噪点；
3. 按设施家族最大主体框等比缩放；
4. 底部对齐到统一地线；
5. 输出 `512 × 512` Pixi Texture；
6. 按 `assetId + source` 缓存，禁止每帧重复处理。

## 5. 清理规则

以下内容从运行资源体系清退：

1. `public/assets/city01/product/facilities/*`：文件名与图像语义错位。
2. 所有整张源精灵图：仅保留切图追溯用途。
3. `build_sheet` 中带英文文字、残缺文字和小条形碎片。
4. 各家族自带的尺寸不一致菜单图标和选择框。
5. 地块中的同类近重复图：每类先保留一张标准图，其余转入候选库。

“清退”表示：

- 不进入 `globalAssetCatalog`；
- 不参与预加载；
- 不允许业务代码通过路径直接引用；
- 源文件暂时保留用于对照，确认无引用后再物理删除。

## 6. 剩余切图批次

### P0-ASSET-02 地块基础

统一输出 `512 × 256`：

- 草地地块；
- 铺装地块；
- 碎石地块；
- 粗糙施工地块。

近重复铺装、碎石和粗糙地块先清退，不同时接入。

### P0-ASSET-03 建设与选址反馈

统一输出 `512 × 256`：

- 可建设；
- 警告；
- 不可建设；
- 占地网格。

所有提示文字由代码渲染，图片内不得存在英文或中文。

### P0-ASSET-04 设施特效

统一输出 `512 × 512`：

- 浅色烟雾；
- 深色烟雾；
- 通电光柱；
- 电火花。

特效必须与设施主体解耦，可以独立定位、缩放、调透明度和关闭。

### P0-ASSET-05 模块化电网线路

当前网格素材将线路和电塔画在同一张图中，不能直接拉伸。必须继续切为：

- 直线段；
- 转角段；
- 流向光带；
- 过载光带；
- 断电线段；
- 独立电塔；
- 告警标记。

## 7. 验收与错误处理

任一项命中即禁止进入运行目录：

- 引用 `city01/product/facilities`；
- 引用整张源精灵表；
- 画布或锚点不符合规格；
- 状态缺失；
- 图片包含文字；
- 透明边存在明显残片；
- 同一设施状态切换时主体跳动；
- 真实截图中业务语义不正确。

CI 必须同时验证资源路径、目录规则、统一画布元数据、Asset ID 唯一性和运行截图。CI 通过但真实截图不正确，仍判定失败。
