# City-01 城区一体化 V1

## 目标

City-01 的五张产品城区图原始版本都带有完整的方形或菱形外围道路、抬高路沿和角落地台。直接放入手工城市地图后会形成五个互不相连的悬浮贴片。

本阶段不重画城区主体，而是在运行时首次加载纹理时，按城区类别建立独立保留蒙版：

- 保留主体建筑、内部街道、广场、绿化和具有业务意义的车辆；
- 删除外围道路、抬高路沿、角落地台和孤立车辆；
- 边缘进行小范围羽化，避免硬裁切；
- 生成纹理按城区类型和源文件缓存，不进入逐帧渲染路径。

| 东部老城区 | 钟楼街区、商住街区、前排建筑、喷泉广场、树木、黄色停放车辆 | 外围道路、黑色车辆、厚路沿 |

## 运行机制

- 入口：`PixiAssetLoader`。
- 处理器：`City01DistrictTextureFactory`。
- 处理范围：仅十个 City-01 城区运行时资源 ID，即五类城区的夜间和停电状态。
- 缓存键：`城区类型 + 源文件路径`。
- 原始 PNG 保持不变，其他城市和普通建筑资源不进入该处理流程。

## 验收

每增加一个城区，都必须同时通过：

1. 内容与资源校验；
2. 单元测试；
3. TypeScript 类型检查；
4. 生产构建；
5. City-01 城市视图真实截图；
6. City-01 电网视图真实截图。

V1 最终截图确认：五类城区外围方形路框均已消失，主体建筑和业务辨识保持完整，任务 HUD、道路、电网诊断、车辆及设施渲染未发生回归。

## 后续

下一阶段不再调整城区主体蒙版，转入城区与主干路之间的接驳道路、统一接触阴影和城区尺度校准。
