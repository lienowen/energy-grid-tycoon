# City-01 运行素材统一标准 V1

## 1. 目标

City-01 不再通过错名产品图、整张精灵图、带文字碎片或临时运行时缩放拼出设施。所有可见设施必须先进入统一运行素材体系，再允许注册到全局 Asset Catalog。

本标准对应《Energy Grid Tycoon 游戏开发文档 V1.1》的地图分层与 P0 素材要求。

## 2. 目录职责

| 目录 | 职责 | 是否允许运行时直接引用 |
|---|---|---:|
| `public/assets/single/v1` | 从源精灵表切出的透明输入图 | 仅通过统一 Catalog 和纹理工厂允许 |
| `source/single-assets-v1` | 原始精灵表与切图追溯 | 否 |
| `public/assets/city01/product/facilities` | 错名历史设施包 | 已物理删除 |
| `City01UnifiedFacilityCatalog.ts` | 设施运行入口 | 是 |
| `City01UnifiedSupportCatalog.ts` | 地块、选址与特效运行入口 | 是 |
| `City01UnifiedGridCatalog.ts` | 模块化电网线路运行入口 | 是 |

## 3. 设施运行规格

每个设施家族必须满足：

- 输出画布：`512 × 512`，RGBA。
- 统一锚点：`x=0.5`、`y=0.9115`。
- 统一地线：`467 px`。
- 必备状态：`active`、`construction`、`offline`、`fault`。
- 同一设施不同状态必须保持相同视觉尺度和落地点。
- 不允许烘焙名称、按钮文字、错误提示或状态说明文字。
- 不允许直接加载整张精灵表。
- 不允许透明边外残留箭头、文字碎片或其他设施残片。

运行时首次加载单图时执行：

1. 读取 Alpha 主体边界；
2. 去除极小边缘噪点；
3. 按设施家族最大主体框等比缩放；
4. 底部对齐到统一地线；
5. 输出 `512 × 512` Pixi Texture；
6. 按 `assetId + source` 缓存，禁止每帧重复处理。

## 5. 清理规则

以下内容从运行资源体系清退：

1. `public/assets/city01/product/facilities/*`：文件名与图像语义错位，已物理删除。
2. 所有整张源精灵图：仅保留在 `source` 目录用于重切和追溯。
3. `build_sheet` 中带英文文字、残缺文字和无法复用的小条形碎片。
4. 各家族自带的尺寸不一致菜单图标和选择框。
5. 地块中的同类近重复图：每类只批准一张标准图。
6. 线路与电塔粘连图：只作为裁切输入，不允许作为运行输出拉伸。

“清退”表示：

- 不进入 `globalAssetCatalog`；
- 不参与业务预加载；
- 不允许业务代码通过路径直接引用；
- 错名产品设施文件直接删除；
- 仍有重切价值的组合源图只保留为纹理工厂输入。

## 7. 验收与错误处理

任一项命中即禁止进入运行目录：

- 引用已删除的 `city01/product/facilities`；
- 运行时直接引用整张源精灵表；
- 画布或锚点不符合规格；
- 状态缺失；
- 图片包含文字；
- 透明边存在明显残片；
- 同一设施状态切换时主体跳动；
- 模块化线路中仍包含电塔残边；
- 真实截图中业务语义不正确。

CI 必须同时验证资源路径、物理清理、统一画布元数据、Asset ID 唯一性、裁切规则和运行截图。CI 通过但真实截图不正确，仍判定失败。
