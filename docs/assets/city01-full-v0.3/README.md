## 统一规格
- 1024×768
- 透明 PNG
- 2:1 等距视角
- 左上光源
- 默认锚点：x=0.5, y=0.9115（像素 512,700）

## 上传建议
仅上传 `sprites/` 中的 PNG 到：
`public/assets/city01/full/`

再将 `integration/asset-catalog-snippet.json` 合并到项目素材注册中。

## 我主动补充的判断
这包已经足够让 City-01 形成完整基础视觉，不再只是“城区 + 电站”。

但如果你要继续提高地图拼装自由度，下一批最值得补的是：
1. road-dead-end（道路尽头）
2. road-bridge（桥）
3. coast-cliff（海岸断崖）
4. harbor/pier（码头）
5. small-park（小绿地）
6. empty-grasslot（空草地）
7. beach-open（开放沙滩）

这些不是当前接入前置条件，但会明显提升地图自然度。
