# City-01 基础地图与道路拓扑规范 V1.1

> 状态：P0 强制开发基线  
> 适用分支：`feat/commercial-standard-recovery-v1`  
> 原则：先完成完整基础地图，再接入道路、城区、设施和装饰。

## 1. 本次架构结论

City-01 停止以下实现方式：

- 多块海岸 PNG 共同决定岛体轮廓；
- 先摆道路图，再用黑线、长支路或大块遮盖修补连通；
- 为提高素材使用率，把所有素材强行放进地图；
- 让城区图片自带地台替代整张地图地基；
- 在正式运行场景中临时绘制灰块、粗线或大面积遮罩充当资产。

City-01 必须使用一张完整基础地图，统一承载海洋、连续陆地、海岸和基础地表。道路先由拓扑配置确定连通关系，再选择出口匹配的道路单图。城区、设施和装饰仅作为上层对象摆放。

## 2. 地图分层

| 层级 | 内容 | 允许素材 | 强制验收 |
|---|---|---|---|
| L0 基础地图 | 海洋、连续陆地、统一海岸、基础地表 | 单张 `city01.map.base` | 单独显示即是一张完整地图，无矩形水块、漂浮岛和拼接缝 |
| L1 道路 | 主干路、次干路、城区入口、设施短接驳 | 标准道路单图、路口、桥、短连接件 | 所有可见出口相接，不跨海、不穿建筑 |
| L2 城区 | 住宅、商业、工业、公共服务、老城区 | 五类城区主体和状态层 | 入口朝向道路，比例一致，不再决定地图边缘 |
| L3 能源设施 | 光伏、风机、燃气、储能、变电站、输电节点 | 通过素材准入门的设施包 | 设施语义正确，连接点对准电网，不散落在海岸 |
| L4 装饰 | 公园、森林、车辆、码头、海边小物 | 装饰单图 | 只填充空白，不阻断道路和交互 |
| L5 状态与特效 | 供电、停电、过载、施工、事件、选择反馈 | Mask、Shader、粒子、小纹理 | 不修改布局，不遮挡主要建筑和道路 |

## 3. 基础地图字段标准

| 字段 | 类型/必填 | 标准 | 错误处理 |
|---|---|---|---|
| `assetId` | string / 必填 | `city01.map.base` | 重复 ID 阻止构建 |
| `file` | string / 必填 | `city01-map-base@2x.webp`，保留 PNG 源文件 | 文件缺失时显示可见错误底图并记录错误 |
| `designSize` | object / 必填 | 2048×1536 @2x；逻辑基准 1024×768 | 真实像素与声明不一致时拒绝合并 |
| `anchor` | object / 必填 | `{x:0.5,y:0.5}` | 镜头、道路和内容摆位必须共用原点 |
| `includes` | array / 必填 | 海洋、岛体轮廓、海岸、基础草地/铺装分区、必要浅滩 | 缺失连续区域则基础地图验收失败 |
| `excludes` | array / 必填 | 城区、设施、车辆、标签、金额、按钮、事件文字 | 出现烘焙业务文字或交互对象即退回 |
| `safeMargin` | number / 必填 | 四周至少 80px 海洋安全区 | 桌面和移动裁切后不得露透明边或黑边 |
| `preload` | enum / 必填 | `level` | 非法值回退并在开发环境报错 |

## 4. 道路拓扑字段标准

道路必须先作为图结构完成逻辑设计，再映射到道路素材。每个城区有 1–2 个入口；光伏、风场、储能等园区只允许短接驳，不要求每个设施直接连接主干道。

| 字段 | 类型/必填 | 规则 | 示例 |
|---|---|---|---|
| `nodeId` | string / 必填 | 路口、入口或接驳点唯一 ID | `road.central.cross` |
| `position` | object / 必填 | 统一地图坐标，禁止直接混用 Pixi 像素坐标 | `{x:55,y:48}` |
| `edgeId` | string / 必填 | 连接两个节点，不得形成未声明断头 | `road.central.to-industrial` |
| `roadClass` | enum / 必填 | `arterial` / `collector` / `access` | `collector` |
| `exits` | enum[] / 必填 | 等距方向 `NW/NE/SE/SW`，与相邻图块匹配 | `[NW,SE]` |
| `assetId` | string / 必填 | 与出口、宽度和道路等级匹配 | `road.straight.ne-sw` |
| `width` | number / 必填 | 同等级显示宽度统一，不允许任意拉伸补缝 | `328` |
| `isDeadEnd` | boolean / 必填 | 仅施工地、停车场或明确终点可为 true | `false` |
| `maxAccessLength` | number / 必填 | 短接驳不超过一个标准地块 | `1 tile` |

自动校验必须证明：所有城区入口从主路可达；道路边不跨越海洋；除明确终点外不存在断头路。

## 5. 缺失素材与切图规则

- 缺少道路出口组合时，从同视角、同宽度的原始道路 PNG 中裁出专用透明单图，保留原路沿、阴影和光照。
- 缺少海岸过渡件时，优先修改基础地图海岸轮廓，不继续叠加多个海岸水块。
- 基础地图只制作一次，不为每个城区重复生成独立海洋或岛体底图。
- 新切素材必须登记来源文件、裁切框、尺寸、锚点、出口方向、用途、目标目录和验收截图。
- 自动裁切可以用于生产，但运行时不得每帧生成纹理；最终资产应预生成或首次加载后缓存。
- 文件名与实际图片语义不一致时，先修正 Asset Catalog 映射，禁止按错误文件名开发。

## 7. 一票否决项

以下任一问题出现，地图任务判定失败：

- 基础地图仍依赖外部海岸块才能看起来完整；
- 道路视觉断开或出口方向不匹配；
- 明显矩形水块、漂浮海岸、绿色大底板或图块压叠；
- 城区、设施像样品摆件，间距和比例失衡；
- 为使用素材而破坏连通、视角或业务语义；
- CI 通过但真实首屏仍然混乱。

失败后必须撤回对应改动。禁止用“代码通过”“素材已经接入”代替地图验收。
